# Getting Started

**Goal:** Catch your first regression in 15 minutes.

For one end-to-end orientation covering installation, concepts, artefacts,
providers, the Python API, security boundaries, and contribution, start with the
[Newcomer guide](Newcomer-Guide.md).

## Your Path

| Step | What You'll Do | Time |
|------|----------------|------|
| 0. [Newcomer guide](Newcomer-Guide.md) | Understand the complete product and its boundaries | Reference |
| 1. [Quick Install](Quick-Install.md) | Install and verify | 2 min |
| 2. [First Run](First-Run.md) | Test one model/probe with DummyModel | 3 min |
| 3. [First Harness](First-Harness.md) | Run and diff a model/probe matrix | 10 min |
| 4. [Understanding Outputs](Understanding-Outputs.md) | Read the artefacts | 5 min |

**Prerequisites:** Python 3.10+. Git is needed only for source/CI workflows;
API keys are optional because DummyModel works offline.
